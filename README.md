# Epic AI MegaJam 2026

Solo entry by Markus (Claude Code + Unreal MCP). Unreal Engine 5.7, C++ logic with thin Blueprints.

Jam: Nov 12–15, 2026. Theme: TBA.

## Setup
1. Install Git and Git LFS, then `git lfs install`.
2. Clone this repo; the UE project (`.uproject`) lives in the repo root.
3. Right-click the `.uproject` → *Generate Visual Studio project files*, then open.
